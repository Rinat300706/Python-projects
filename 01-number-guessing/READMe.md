

# Project Description

This is is a number guessing game built using Python. The computer randomly generates a number between 
1 - 100 and the player has to guess it.

After each guess the program tells the player whether their guess is too high or too low helping 
narrow down the possible answer. Game conitnues until player guesses correctly.

Program also tracks the number of attempts made, handles invalid inputs to prevent errors, and
allows pllayer to start a new game or exit after winning.

## Features

- Generates a random number between 1 and 100
- Tells the player if their guess is too high or too low
- Keeps track of how many guesses the player makes
- Handles invalid inputs such as letters, numbers outside 1- 100
- Allows the player to play again 
- Allows the player to exit the game
